# Netflix Customer Behaviour Analytics — SQL Project

A SQL-based customer behaviour analytics case study built around a synthetic Netflix-style dataset.

## Objective

Analyze how users discover, watch, engage with, and eventually churn from a streaming platform.

The project focuses on answering business questions rather than simply writing SQL queries.

## Business Areas

- User behaviour
- Content engagement
- Recommendation performance
- Watch behaviour
- Conversion funnels
- Retention
- Churn
- Advertising
- A/B experiments

## Tech Stack

- SQL
- SQLite
- Python
- Pandas
- Power BI

## Database

The database contains:

- Users
- Content
- Subscriptions
- Sessions
- Events
- Recommendations
- Ads
- Experiments
- Daily Activity
- Churn Labels
